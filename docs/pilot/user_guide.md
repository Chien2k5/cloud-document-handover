# HƯỚNG DẪN SỬ DỤNG PORTAL

1. **Đăng nhập:** Nhập username/password để vào hệ thống.
2. **Upload File:** Chọn file để hệ thống tính toán mã SHA-256 và đẩy lên backend.
3. **Quản lý Bàn giao:**
   - **Tạo DRAFT:** Nhập Project ID và FileVersion IDs.
   - **Phát hành READY:** Chuyển trạng thái sang READY.
   - **Xác nhận CONFIRMED:** Bấm xác nhận hoàn tất quy trình bàn giao.
