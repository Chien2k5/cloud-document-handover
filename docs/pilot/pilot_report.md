# BIÊN BẢN NGHIỆM THU PILOT VÀ PHẢN HỒI NGUỜI DÙNG

## 1. Thông tin đợt Pilot
- **Đối tượng:** Nhóm đồ án sinh viên (8 tài khoản).
- **Thời gian:** Tuần 8.
- **Mục tiêu:** Kiểm thử luồng bàn giao tài liệu và xác minh tính toàn vẹn file.

## 2. Đánh giá người dùng
- Giao diện dễ thao tác, phản hồi chính xác trạng thái bàn giao.
- Mã hóa và tính checksum SHA-256 hoạt động ổn định.
